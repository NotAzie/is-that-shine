# Fonts

These files are self-hosted so the piece loads without contacting a font CDN.
Only the Latin subsets are included.

| File | Family | Weight | Style | Source |
| --- | --- | --- | --- | --- |
| `cormorant-300.woff2` | Cormorant Garamond | 300 | normal | [Google Fonts](https://fonts.google.com/specimen/Cormorant+Garamond) |
| `cormorant-300-italic.woff2` | Cormorant Garamond | 300 | italic | [Google Fonts](https://fonts.google.com/specimen/Cormorant+Garamond) |
| `spacemono-400.woff2` | Space Mono | 400 | normal | [Google Fonts](https://fonts.google.com/specimen/Space+Mono) |
| `helvetiker_bold.typeface.json` | Helvetiker Bold | — | — | [three.js examples](https://github.com/mrdoob/three.js/tree/dev/examples/fonts) |
